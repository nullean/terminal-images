# Nullean.TerminalImages: contributor and agent conventions

Terminal image rendering for .NET: Kitty, iTerm2 and Sixel, plus a half-block fallback, with protocol detection. The core has
no package dependencies and is NativeAOT-safe. Integration packages for Spectre.Console, Terminal.Gui v2 and XenoAtom.Terminal sit
beside it. [DECISIONS.md](DECISIONS.md) records the non-obvious choices; read it before changing detection, the terminal I/O, or
what a package depends on.

## Layout

```
src/Nullean.TerminalImages/              core: RgbaImage, Png/, Encoders/, Detection/, Interop/, renderer. No PackageReferences
src/Nullean.TerminalImages.Spectre/      TerminalImage renderable
src/Nullean.TerminalImages.TerminalGui/  TerminalImageView, ApplyDetection
src/Nullean.TerminalImages.XenoAtom/     WriteImage / DetectImagesAsync
tests/*.Tests/                           one test project per src project (TUnit + AwesomeAssertions + CsCheck)
tests/pty/probe_test.py                  runs the published tcat in a pseudo-terminal and plays the terminal
examples/Nullean.TerminalImages.Cat/     tcat, an imgcat-style CLI, and the NativeAOT smoke app
docs/                                    the documentation site: markdown, _docset.yml, the theme CSS and the landing page.
                                         Built by elastic/docs-builder, then scripts/docs-finish.sh (as in snapshots and curb)
docs/images/brand/                       the brand kit, generated by tools/brand/make_brand.py
tools/landing/                           builds docs/terminal-images-landing.html (with a real tcat render and diagnostics)
scripts/docs.sh                          build and serve the docs locally; needs docs-builder on the PATH or DOCS_BUILDER
```

## Build and test

```sh
dotnet build -c Release
dotnet test -c Release
dotnet publish examples/Nullean.TerminalImages.Cat -c Release -o .artifacts/aot-smoke      # NativeAOT: must have no warnings
python3 -I tests/pty/probe_test.py "$PWD/.artifacts/aot-smoke/tcat"                         # macOS and Linux
```

Requires the .NET 10 SDK (pinned in `global.json`). Tests run on Microsoft.Testing.Platform with TUnit. The Terminal.Gui tests start
a real Terminal.Gui application with its ANSI driver.

## Rules

- The core package (`src/Nullean.TerminalImages`) has no `PackageReference`s. No SkiaSharp, no ImageSharp, no
  System.IO.Hashing. The BCL is fine. Host integrations live in their own `Nullean.TerminalImages.<Host>` package.
- `IsAotCompatible` stays on for every `src/` project, and warnings are errors in `src/`, `examples/` and `tests/` alike: no reflection, no `Activator`, no
  runtime `Regex`. P/Invokes use `[LibraryImport]`.
- Detection parsing is pure and tested against recorded terminal replies. Never block without a timeout, and always
  restore the terminal's mode in a `finally`. Terminal I/O needs the pty test, not just a fake channel: a fake cannot see a
  `poll`-on-`/dev/tty` hang.
- Never run `tmux set` (or otherwise change the user's terminal or multiplexer settings) unless the caller opted in.
- Provenance: do not copy code from copyleft projects (GPL, LGPL, AGPL, MPL), and do not copy from XenoAtom.Terminal.
  Port from a permissive project only with the licence kept in `THIRD-PARTY-NOTICES.md`.
- Tests are mutation-checked: break the code on purpose and confirm the suite fails. Make sure the mutation compiles (the
  analyzers reject many) and that it actually applied, or a passing run proves nothing.
- Say what is verified and how, and what is not: the README status table is the place.
- Record non-obvious choices in DECISIONS.md in the same change.
- Never publish packages or push tags without the owner's approval. Releases are a manual workflow run on a tag, through nuget.org
  trusted publishing (no key), as in the other nullean repos.

## Releasing

A tag `X.Y.Z` (MinVer) runs CI. Publishing is `gh workflow run ci.yml --ref X.Y.Z`: the `release` job then packs, checks every
package has the tag's version, logs in with trusted publishing (the org-wide `secrets.NUGET_USER`), pushes the core first,
and creates the GitHub release.
